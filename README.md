## 📖 The Story: From Hackathon to Development Cycle

SurplusLink was originally born during the **PixelRush Hackathon 2026** by Team Nankhatai (TSU-16). Built under a strict 24-hour deadline, our goal was to solve problem statement `[PS-06]` by designing and building a user interface for managing surplus resources.

As a 1st-year CSE student, I decided not to let this project gather dust after the hackathon ended. I am currently using this repository to practice the **Software Development Life Cycle (SDLC)**. Every 14 days, I run a new "Dev Cycle" to add features, improve the code, and apply the new technologies I am learning in college.

## ✨ Current Features
- **Semantic HTML Structure:** Built with clean, readable HTML5.
- **Custom CSS Styling:** Translated pixel-perfect from our original Hackathon Figma files.
- **Responsive Design:** Adapts to different screen sizes using modern CSS techniques.
- **Version Controlled:** Maintained using proper Git branching and commit practices.

## 🛠️ Local Development Setup

Want to run this project locally on your machine? Follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/itsdguptacg/SurplusLink.git
   ```
2. **Navigate to the project folder:**
   ```bash
   cd SurplusLink
   ```
3. **Run the site:**
   - You can simply double-click the `index.html` file to open it in your browser.
   - *Recommended:* Use the [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) extension in VS Code for live reloading as you edit.

## 🚀 Development Roadmap (What's Next)
